Two narrow changes address avoidable work. Seam publication copies unchanged typed core attributes and indices directly into final buffers, avoiding the full-core JavaScript array round trip and per-triangle loop. Only skirts and connectors are rebuilt. Startup now prepares the existing near front/back and far transparent fade programs using the real stamping path. Three private materials retain those programs between tiles, across both existing shadow-light counts, and are released on terrain teardown. This closes a warmup gap found by inspecting the shader variants; the exact fraction of driver stalls removed is not established by this single diagnostic.
